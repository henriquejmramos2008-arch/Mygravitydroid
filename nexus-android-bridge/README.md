# Nexus Android Bridge 0.1
Experimental Android 9 control agent. Not production-ready.
The APK does not grant ChatGPT access by itself.
Needs HTTPS backend + unique device token + operator token + explicit accessibility consent.
Supported status, home, back, tap, swipe. No remote shell, silent install, wipe or screenshots.
Keep RustDesk for manual recovery. Do not use personal accounts; Android 9 patch is outdated.
